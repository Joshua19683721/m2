# 場景內容生成契約（Content Authoring Brief）

你是這個「場景式英文輸入練習」專案的**內容編輯**。只寫資料，不寫程式碼、不做設計。

## 資料來源

`data/_scene_spec_extra.json` — 新增場景的規格，每個場景有一份 `words` 清單，
這份清單來自 Cambridge English《A2 Key / A2 Key for Schools Vocabulary List》
（字母序主詞表，共 1713 條）尚未被主題表收錄的詞。

每個 `words` 項目長這樣：

```json
{ "en": "because", "pos": "conj", "examples": ["Because it was late, we went home."] }
```

`examples` 有時有、有時沒有（Cambridge 只在需要限縮詞義時才給例句）。

## 你要產出的檔案

`data/parts/<batch>.json` — 一個 JSON **陣列**，內含你負責的每個場景物件：

```json
{
  "id": "grammar-core",
  "icon": "🧩",
  "name": "基礎文法核心詞",
  "nameEn": "Core Grammar Words",
  "summary": "…（照抄規格）",
  "note": "…（照抄規格，這段是給學生的練習提醒）",
  "group": "文法基礎",
  "words":     [ { "en": "...", "zh": "...", "ipa": "..." } ],
  "phrases":   [ { "en": "...", "zh": "...", "ipa": "..." } ],
  "sentences": [ { "en": "...", "zh": "..." } ],
  "tips":      [ "…", "…", "…" ]
}
```

## 硬性規則

### 1. words —— 最重要
- **規格 `words` 清單裡的每一個 `en`，都必須原樣出現在你的 `words` 裡，一個都不能漏、
  不能改名、不能合併。** 這是覆蓋率 100% 的唯一保證。
- 你**可以額外補上**同主題、同難度的詞（建議補到 60–80 個，讓場景夠紮實）。
- 每個 word 都要有 `zh`（繁體中文，台灣用語）與 `ipa`（英式 IPA）。
- 規格裡 `en` 帶斜線的（如 `centre/center`），**保留原字串當 `en`**，另外在 `zh` 註明另一個說法
  （例：`"centre/center": "中心／中心（美式）"`）。

### 2. phrases —— 14 筆
- 這個主題真正會一起出現的多字片語：介系詞片語、動名詞片語、常用搭配。
- 例：grammar-core → `be good at`、`have to`、`as well`；grammar-adverbs → `at least`、`all the time`。
- 每筆都要 `zh` + `ipa`。

### 3. sentences —— 14 筆
- **完整的 A2 級英文句子，6–14 個字。**
- 每句盡量用到這個場景的 2–3 個詞。
- 只放 `en` 與 `zh`（App 會即時用詞庫組合音標，所以**不要**自己寫 `ipa`）。
- 句子必須是**自然、正確、道地**的英文，不能是中國式英文。

### 4. tips —— 3 筆
- 繁體中文（台灣），一到兩句，給這個主題的**具體練習建議或易錯提醒**。
- 不要在 tips 裡塞英文單字（除非是指引學生去注意的例詞）。

### 5. IPA 寫法
- 英式（British）发音。
- **不要**加前後斜線 `/ /`。
- 音節之間用小圓點：ˈwɑː.ʃɪŋ mə.ʃiːn
- 重音：主要重音 ˈ 放在該音節前，次要重音 ˌ。
- 只能用真正的 IPA 字母：ː ɪ ʊ ə ɜː ɔː ʌ ɒ æ e θ ð ʃ ʒ ŋ tʃ dʒ aɪ eɪ ɔɪ əʊ aʊ ɪə eə ʊə
- 範例：
  - `because` → bɪˈkɒːz
  - `a lot of` → ə lɒt əv
  - `get up` → ˌɡet ˈʌp
  - `toothache` → ˈtuː.θeɪk
  - `friendly` → ˈfrend.li

### 6. 文字格式
- `en` 裡的撇號一律用**半形直引號** `'`（不要用 `’`），App 會用正規表示式切字。
- `en` 裡不要出現 `/`（規格原本就有的斜線例外，照抄即可）。
- `en` 不可為空，不可放「a, b, c」這種清單（規格原有寫法照抄）。
- `zh` 不可出現任何拉丁字母。
- 嚴格 JSON：雙引號、無註解、無尾逗號、UTF-8 無 BOM。

## 品質要求（這是這個專案的價值所在）

1. **英文要對**。句子必須母語者讀起來自然，時態、主詞動詞一致、冠詞正確。
2. **中文要準**。`zh` 是給台灣國中生看的解釋，要用台灣用語（例：影片、腳踏車、電梯、
   垃圾、廚房、鉛筆），不要用大陸用語（影片/視頻、腳踏車/自行車、電梯/電梯）。
3. **詞性要對**。名詞、動詞、形容詞的 `zh` 不能搞混（例：`mine` 若是名詞就是「礦」）。
4. **不要臆造詞**。所有詞都必須是 Cambridge A2 Key 詞表裡的，或該主題常見的 A2 等級詞。
5. 詞典裡沒有把握的詞，寧可 `zh` 寫得保守，也不要編。

- [ ] 沒有任何 sentence 有 `ipa`
- [ ] 沒有彎引號 `’`、沒有尾逗號
